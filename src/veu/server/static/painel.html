Proteger um arquivo

Planilhas, documentos e apresentações saem no mesmo formato, com os dados trocados por marcadores como [CPF_1]. Envie o arquivo protegido para a IA. Quando ela devolver um arquivo, use Colocar os dados de volta.

    Proteger um texto

    Cole um texto, copie a versão protegida para a IA e depois cole a resposta para ver os dados reais.

    Colocar os dados de volta na resposta da IA

    Usar com aplicativos

    Escolha onde você usa IA. Cada opção mostra o que fazer, sem precisar programar.

    ChatGPT, Claude e Gemini no navegador

    Use a página do Véu (nada para instalar) ou a extensão, que protege o que você cola nos sites das IAs.

    Abrir a página Como instalar a extensão

    Claude Desktop

    O Claude passa a ler planilhas, documentos e páginas do Notion com os dados já protegidos.

    Cursor

    O Cursor ganha as ferramentas do Véu para ler arquivos sem expor dados e segredos.

    n8n, Make, Zapier e outros apps com IA

    Onde o aplicativo pede o endereço da OpenAI (Base URL), cole este. A chave da OpenAI continua a mesma.

    Para programadores

    Troque só o endereço do cliente. Funciona com OpenAI, Anthropic, Gemini, Ollama e outros.

    Marque o que o Véu deve esconder antes de enviar para a IA. Ao salvar, o Véu reinicia em poucos segundos.

        Nunca esconder
