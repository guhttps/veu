Instalar o Véu

Dois minutos, sem saber programar e sem pedir permissão de administrador.

Voltar

Precisa instalar?

Para colar textos no ChatGPT, no Claude ou no Gemini, você não precisa instalar nada: use a página do Véu.

Instale no computador para:

  • proteger planilhas, documentos e PDFs inteiros;
  • conectar o Claude Desktop ou o Cursor;
  • proteger aplicativos como n8n, Make e Zapier.

1 No Windows

  1. Aperte a tecla Windows, digite PowerShell e aperte Enter.
  2. Copie o comando abaixo, cole na janela azul (botão direito do mouse cola) e aperte Enter:
    irm https://guhttps.github.io/veu/instalar.ps1 | iex
  3. Espere a mensagem Pronto!. O painel do Véu abre sozinho no navegador.

Fica um atalho Véu na área de trabalho e no menu Iniciar. Se o Windows perguntar se pode continuar, responda que sim.

2 No Mac ou no Linux

  1. Abra o Terminal (no Mac: Command + Espaço, digite Terminal e aperte Enter).
  2. Copie, cole e aperte Enter:
    curl -LsSf https://guhttps.github.io/veu/instalar.sh | sh
  3. Quando aparecer Pronto!, o painel abre no navegador. Deixe a janela do Terminal aberta enquanto usar o Véu.

3 Usar

O painel do Véu abre no navegador. Lá você:

  • Protege um arquivo: arraste uma planilha, um documento ou um PDF e baixe a versão protegida para enviar à IA. Quando a IA devolver um arquivo, use Colocar os dados de volta.
  • Conecta o Claude Desktop ou o Cursor com um clique.
  • Copia o endereço para n8n, Make, Zapier e outros aplicativos.
  • Escolhe o que proteger (nomes, documentos, cartões, senhas...) marcando caixinhas.
  • Marca Ligar o Véu junto com o computador, se quiser que ele fique sempre ligado.

Para abrir de novo depois, use o atalho Véu. Seus dados não saem do computador: o Véu só manda para a IA a versão protegida.

O que o instalador faz e como desinstalar

Ele instala o uv, um gerenciador de Python conhecido e de código aberto, e com ele o Véu, na sua pasta de usuário. Ele não mexe no sistema nem precisa de administrador. O código do instalador está no GitHub.

Para desinstalar, rode no mesmo lugar: veu atalhos --remover e depois uv tool uninstall veu.
